# szrehot — 深圳房地产热点资讯 Skill 迁移设计

> Status: Approved (2026-07-21)
> Author: zycyyyya / Codex

## 目标

将 finhot（金融保险圈资讯 Skill）迁移为 szrehot（深圳房地产热点资讯 Skill），核心变更：

1. **行业迁移**：金融保险 → 深圳房地产（聚焦深圳市场）
2. **技术迁移**：删除 neodata/westock-data/Kimi WebBridge，引入 Codex 浏览器 + 搜狗微信搜索 + Tavily 兜底
3. **分类体系**：原五类 → 新六类（政策法规/市场行情/城市更新/标杆公司/研究报告/观点洞察）
4. **双视角评分**：从业者 + 购房者/投资者
5. **微信公众号**：搜狗微信搜索（主力 Codex 浏览器 + 兜底 Tavily），搜索词必须拼接时间限定

- 搜索关键词格式：深圳{主题词} {YYYY}年{M}月（Agent 动态获取当前日期）
- 主题词列表：楼市、房价、土拍、买房、保障房、公积金、旧改、城市更新、工改工、棚改
- 主力获取：Codex 浏览器打开搜狗结果页 → AI 提取 → Codex 浏览器直开 mp.weixin.qq.com 全文
- 兜底获取：Tavily advanced + include_raw_content 按标题跨站搜索
- 搜狗频控/验证码 → 跳过不阻塞

## 双视角评分体系

### 从业者视角（100 分）

| 维度 | 分值 | 判断口径 |
|---|---:|---|
| 行业相关性 | 25 | 是否直接涉及深圳房地产政策、市场、公司 |
| 来源权威性 | 20 | 政府官网/官方公告最高，主流媒体次之，自媒体最低 |
| 业务影响 | 20 | 是否影响销售策略、定价、推盘节奏、客户预期、旧改项目进展 |
| 时效性 | 15 | 6小时内最高，24小时内较高，超过3天递减 |
| 内容深度 | 10 | 是否有数据、政策条文、公告原文，而非一句快讯 |
| 可行动性 | 10 | 是否能转化为客户沟通、推盘调整、风险提示 |

### 购房者/投资者视角（100 分）

| 维度 | 分值 | 判断口径 |
|---|---:|---|
| 购房相关性 | 25 | 是否直接影响深圳买房决策（价格、政策、供应） |
| 来源权威性 | 20 | 同上 |
| 决策影响 | 20 | 是否影响购房时机、区域选择、价格判断、贷款策略、周边旧改影响 |
| 时效性 | 15 | 同上 |
| 信息实用度 | 10 | 是否有具体数据、楼盘名、价格、时间节点 |
| 可行动性 | 10 | 是否能转化为看房、出价、贷款申请等具体行动 |

## 迁移风险与应对

| 风险 | 应对 |
|---|---|
| 搜狗微信搜索频控 | 跳过不阻塞，RSS+百度兜底 |
| RSSHub镜像站不稳定 | 多路由冗余，镜像站可配置 |
| Codex浏览器操作耗时 | 微信/垂直站为补充源，默认只走RSS |
| Tavily API限流/付费 | 无Key则跳过，只用摘要 |
| 百度搜索结果噪音 | 深圳房产关键词过滤+AI二次筛选 |
| 垂直站改版 | AI自适应提取，失败跳过 |
