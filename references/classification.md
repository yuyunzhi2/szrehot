## 时效窗口

仅保留发布时间在**窗口起点 0:00 ~ 执行当前时间**（北京时间）内的条目。窗口起点规则：周一运行=上周五 0:00，其余日子=前一天 0:00。无发布时间且全文获取失败→丢弃；全文成功→保留标注「时间未知」排末尾。

**红线**：时效审核是硬性门槛，窗口外条目直接丢弃。不得通过标中性情绪、手动拼接等方式变相保留窗口外条目。

## 地域审核（硬性门槛）

主体不在深圳的新闻（上海/广州/北京等本地政策、土拍、旧改）即使属房地产也丢弃。原文未提及深圳时，不得虚构关联。

## 结构化标题去重规则（轨4）

周报/月报/数据报等结构化标题，不同公众号转载同一期报告时标题措辞不同但内容一致，需要基于「报告类型+时间范围」去重。

### 识别规则

| 报告类型关键词 | 映射 | 示例标题 |
|---|---|---|
| 周报/周度/一周/周刊 | weekly | "第30周深圳楼市周报(7.20-7.26)" |
| 月报/月度/月刊 | monthly | "2026年7月深圳楼市分析" |
| 季报/季度 | quarterly | "2026年Q2深圳楼市季报" |
| 年报/年度 | yearly | "2026年深圳楼市年报" |
| 数据/成交数据/行情/情报局 | data | "深圳二手房成交数据(第161期)" |
| 第一时间 | daily_brief | "2026年7月30日全国楼市第一时间" |

### 时间范围提取优先级

1. **周号**：第N周 / 第N期 → 提取周号+年份（如 weekly:30:2026）
2. **日期范围**：M.D-M.D / M月D日-M月D日 → 提取起止月日（如 weekly:7.20-7.26）
3. **年月**：YYYY年M月 / YYYY.M → 提取年月（如 monthly:2026-7）

### 去重逻辑

两条标题提取到相同的 {report_type}:{time_key} = 重复，仅保留发布时间更早/来源更权威的一条。

### 示例

| 标题A | 标题B | 去重键 | 判定 |
|---|---|---|---|
| 2026年第30周深圳楼市周报(7.20-7.26) | 深圳楼市周报(2026.7.20-7.26) | weekly:30:2026 vs weekly:7.20-7.26 | 重复（第30周=7.20-7.26） |
| 深圳楼市二手房成交数据(第161期)7月15-21号 | 深圳二手房成交第161期(7.15-7.21) | data:161 vs data:161 | 重复 |
| 2026年7月30日全国楼市第一时间 | 2026年7月29日全国楼市第一时间 | daily_brief:2026-7-30 vs daily_brief:2026-7-29 | 不重复（日期不同） |

## 情绪分类规则（替代原双视角评分）

每条新闻基于全文语义判定情绪标签 + 影响权重，用于计算当日市场情绪指数。

### 情绪标签

| 标签 | 数值 | emoji | 判定规则 |
|---|---|---|---|
| 看涨 | +1 | 🔴 | 政策松绑/利好、成交量价上升、土地高溢价、企业盈利扩张、保障房供给增加（购房选择面扩大） |
| 看跌 | −1 | 🟢 | 政策收紧/利空、成交量价下跌、土地流拍/低溢价、企业亏损暴雷、供应过剩信号 |
| 中性 | 0 | ⚪ | 纯信息发布无方向性、政策征求意见未定、市场分化涨跌互现、规划调整无明确利好利空 |

### 影响权重（1-5 级）

| 权重 | 信号强度 | 典型场景 |
|---|---|---|
| ★★★★★ (5) | 市级及以上重大政策/数据 | 限购松绑、公积金新政、全市月度成交数据、四大AMC年报 |
| ★★★★ (4) | 区级政策或区域级数据 | 区级保障房供应、核心区土拍、重点旧改规划调整 |
| ★★★ (3) | 行业趋势/全国政策深圳关联 | 全国公积金条例修订、多城楼市趋势分析 |
| ★★ (2) | 单项目/局部动态 | 单个楼盘清盘、非核心区租金数据 |
| ★ (1) | 边缘关联/信息性 | 网友问答、一般租赁招租 |

### 指数计算

`情绪指数 = 50 + 50 × Σ(情绪值ᵢ × 权重ᵢ) / Σ权重ᵢ`

- 0 = 极度看跌，50 = 中性，100 = 极度看涨
- 偏离50越远 = 新闻面共识方向越强；靠近50 = 多空交织或信息偏中性

### 指数区间语义

| 区间 | 含义 | 日报措辞 |
|---|---|---|
| 0-20 | 极度看跌 | 市场情绪显著偏空 |
| 20-35 | 偏空 | 市场情绪偏弱 |
| 35-45 | 弱空 | 市场情绪略偏谨慎 |
| 45-55 | 中性 | 市场情绪多空交织 |
| 55-65 | 弱多 | 市场情绪略偏积极 |
| 65-80 | 偏多 | 市场情绪偏暖 |
| 80-100 | 极度看涨 | 市场情绪显著偏多 |

### 分类 × 情绪交叉参考

| 分类 | 常见情绪倾向 | 说明 |
|---|---|---|
| policy | 取决于方向 | 松绑=看涨，收紧=看跌，征求意见=中性 |
| market | 取决于数据 | 量价齐升=看涨，量价齐跌=看跌，分化=中性 |
| urban_renewal | 偏中性 | 规划调整多为信息性，除非涉及重大拆迁赔偿或产业导入 |
| company | 取决于业绩 | 拿地/盈利=看涨，暴雷/亏损=看跌，一般公告=中性 |
| research | 偏中性 | 研报本身无方向性，除非有明确预测 |
| insights | 取决于观点 | 看多=看涨，看空=看跌，均衡=中性 |


## 周度/月度情绪汇总规则

### 数据源

每日情绪指数由步骤11写入 `sentiment_log.jsonl`（与 `dedup_index.jsonl` 同目录），格式：

```json
{"date":"2026-08-04","index":75.4,"label":"偏多","bullish":{"count":10,"weight":34},"neutral":{"count":7,"weight":21},"bearish":{"count":1,"weight":4},"weightedSum":30,"totalWeight":59,"newsCount":18}
```

### 汇总算法

`汇总指数 = Σ(日index × 日newsCount) / Σ(日newsCount)`

- **加权平均**：新闻多的日子对市场情绪反映更充分，不应与新闻少的日期简单等权
- **跳过无数据日**：newsCount=0 的日期（周末休市/未生成日报）不计入分母
- **区间语义**：与日指数相同（0-20 极度看跌 … 80-100 极度看涨）

### 触发规则

| 运行日期 | 触发汇总 | 时间范围 |
|---|---|---|
| 周一 | 周度 | 上周一~上周日 |
| 每月1日 | 月度 | 上月1日~上月末日 |
| 周一且1日 | 周度+月度 | 两个都触发 |
| 其余日子 | 无 | — |

### 周度汇总输出格式

```markdown
## 上周市场情绪汇总（8.1-8.7）

**周度情绪指数：72.3（偏多）**

| 日期 | 指数 | 标签 | 新闻数 |
|------|------|------|--------|
| 8.1 周一 | 75.4 | 偏多 | 18 |
| 8.2 周二 | — | 休市 | 0 |
| ... | ... | ... | ... |

> 交易日5天，总新闻67条，加权平均指数72.3（偏多）。
```

### 月度汇总输出格式

```markdown
## 2026年7月市场情绪汇总

**月度情绪指数：68.5（偏多）**

| 日期 | 指数 | 标签 | 新闻数 |
|------|------|------|--------|
| 7.1 | 62.3 | 弱多 | 13 |
| ... | ... | ... | ... |

> 交易日22天，总新闻286条，加权平均指数68.5（偏多）。
```
