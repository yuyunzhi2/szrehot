# 周报生成流程（仅周一 · 日报 D 阶段完成后必执行）

> 输入：`大瑀MD/` 内上周一 ~ 上周日 6 份日报 md（自然周；周日无日报属正常，缺失日期跳过并在周报注明，不补造）。
> 输出：`大瑀MD/深圳资产周报_{上周一起}_{上周日}.md`（如 `深圳资产周报_2026-08-31_2026-09-05.md`），对话中原样粘贴全文并告知路径。

## 步骤

1. **齐读**：用 `python -X utf8 -c "print(open(...).read())"` 逐份读出上周全部日报正文（含情绪表、租赁表、法拍 TOP5 与 2000 万子块）。
2. **正文跨日去重**（核心，主模型人工做，脚本不做）：
   - 同一事件多稿合并为一组（如华强南西 16 年两稿、龙华旧改延期两稿），组内保留最早 + 信息最全稿的链接；
   - 同一数据多口径合并（如 8 月成交：中原 / 贝壳 / 克而瑞 / 南都各口径并列，不取舍）；
   - 同一政策事件链按时间线合并叙述（如 8.28 新政：条文 → 首周末爆量 → 成交验证）；
   - 统计去重后独立事件数与六类分布、看涨 / 中性 / 看跌计数（以正文情绪标签为准重算，不沿用各日报情绪表——历史日报情绪表与正文可能口径不一）。
3. **周情绪表**：数据源 `sentiment_log.jsonl`，按新闻数加权平均（与日报 `--weekly` 同口径，可直接复用当日日报内的周汇总表；缺失日期跳过）。
4. **租赁合并表**：各日报租赁表按（地址 + 面积 + 底价）跨日去重（如汇智时代广场在 9.02 / 9.03 重复、海昱宿舍与银湖汽车站在 9.04 / 9.05 重复口径），保留"首次出现"列；表头 `首次出现 | 地址 | 面积(㎡) | 底价(元/㎡/月) | 用途`；末尾加一周特征行（业态分布 / 最大单宗 / 最低底价）。
5. **法拍合并**：
   - 2000 万子块**全量合并**（一周仅数组，逐组保留：日期·平台 | 基准地址 | 宗数 | 起拍合计 | 评估合计 | 折价率 | 拍卖开始时间）；
   - 周内评估价超千万标的按评估价降序单列清单；
   - 每日 TOP5 明细（6 天约 60 条）**不展开**，注明"见各日报原文"。
6. **落盘 + 对话输出**：UTF-8 无 BOM 写周报 md；对话原样粘贴全文。

## 周报固定结构（五节）

一、周情绪总览（周表 + 解读：最高 / 最低日及原因）→ 二、新闻去重汇总（按政策法规 / 市场行情 / 城市更新 / 标杆公司 / 研究报告 / 观点洞察分组，每组每事件 1~2 行 + 代表链接）→ 三、大宗租赁合并表 → 四、法拍合并（2000 万全量表 + 超千万排序 + TOP5 指向）→ 五、一句话周判断（主线 + 风险提示），尾部 `M月D日|🔴看涨★★★★`。

## 红线

- 周报**不得重新抓取全文、不得重算情绪指数、不得改写各日报表格数值**（含折价率 / 单价）；只做去重、合并、排序与解读。
- 旧日报表格格式不一时（如 2000 万子块缺"宗数"列、租赁旧表头无"宗数"列）**如实呈现缺失**（`-`），不脑补。
- 每组事件至少保留一个可点击原文链接；不暴露基础设施（feed / API / 工具名）。
