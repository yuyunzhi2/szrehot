# 深圳法拍资产日报（原 shenzhen-fapai-daily，已并入 szrehot 每日链阶段 2）

每日从 `D:\Desktop\法拍数据.xlsx` 提取当日法拍数据，生成一份可直接分发的 markdown 日报
（四张表：阿里法拍新增关注top10 / 京东法拍新增关注top10 / 阿里法拍成交top10 / 京东法拍成交top10）。
脚本完成全部解析与格式化，无需手工整理。

## 执行

用托管 Python 环境直接运行脚本（缺省即「今天 + 缺省路径」）：

```bash
PYTHONIOENCODING=utf-8 "C:/Users/Administrator/.workbuddy/binaries/python/envs/default/Scripts/python.exe" \
  -X utf8 "D:/git/opencode/.opencode/skills/szrehot/scripts/generate_fapai_daily.py"
```

可选参数：

- `--date 2026-10-27`（或 `2026年10月27日`）：指定报告日期，缺省为当天
- `--xlsx PATH`：数据源路径，缺省 `D:\Desktop\法拍数据.xlsx`
- `--out-dir DIR`：输出目录，缺省 `D:\Administrator\Documents\大瑀MD`
- `--out PATH`：显式指定输出文件

输出文件名：`深圳法拍资产日报-YYYY-MM-DD.md`。脚本 stdout 会逐表打印数据日期、行数与回退情况，
最终回复中把这些要点带给用户并展示 md 文件。

若报 `ModuleNotFoundError`，先安装依赖再跑：`python -m pip install openpyxl pypinyin`
（同一环境；pypinyin 用于城区拼音排序，缺失时自动退化为字符码降序并告警）。

## 数据源规则

四个 sheet 的结构一致：A 项目名称｜B 网址｜C 当前价/成交价｜D 评估价｜E 拍卖开始时间｜F 热度列。
行按日期分块，日期标记行只在日期列留一个日期，其下方各行（至下一个标记行）属于该日。

| Sheet | 日期列 | 模式 | 入选规则 |
| --- | --- | --- | --- |
| 阿里 | A | 关注 | 当前价与评估价**都有数据**，且 F 围观人数（热度）为有效数字者，按热度降序取前 10 |
| 京东 | B | 关注 | 同上 |
| 阿里成交 | A | 成交 | 当前价与评估价**都有数据**，且 F 出价人数（热度）数字不为 0 |
| 京东成交 | B | 成交 | 当前价与评估价**都有数据**，且 F 含「出价」字样（`X次出价`/`X人出价`）；`X人围观` 一律忽略 |

两组成交表再按折价率入选：**折价率 > 100% 的项目一律入选**，其余按折价率由低到高补足至 10 条
（超过 100% 的条目多于 10 条时全部保留）。

必须兼容的解析细节（脚本已实现）：

- **日期标记三种形态**：中文文本 `2026年10月27日`、ISO 文本 `2026-10-27`/`2026/10/27`、**Excel 日期序列值**（如 `46322` = 2026-10-27，京东 sheet 已出现）。标记行判定附加条件：整行不含 URL。
- **热度列噪声**：`24544.64元/平`、`商业` 等视为无效行直接忽略；`3.63w人围观` 折算为 36300。
- **价格单位混杂**：`284.49万`、`¥355.62万`、`2亿`、裸数字（按万元计）、`1234元`，统一折算成万元展示。
- **回退规则**（用户已确认）：当天无有效数据块时，回退取该 sheet 最新一天的非空数据块，并在表标题下注明实际数据日期与回退情况。

## 呈现规则

- **拍卖开始时间**：只保留到日期，截掉时刻（`11月23日 10:00:00开始` → `11月23日`；`2026-10-24 10:00:00结束` → `2026-10-24`）；`进行中/预告中/已结束` 等无日期文本原样保留。
- **项目名称清洗**：删除 `广东省`、`深圳市`、`关于`、`拍卖`、`位于` 等填充词，删除含 `不动产权证号 / 不含室内物品 / 不包含动产 / 装修按现状 / 带租` 的注记括号（半/全角圆括号、方括号均覆盖），`变卖变卖` 去重。`二拍`、`（第二次）`、`（预售房）`、`（50%份额）`、楼栋别名括号（如 `（峻峰阁）`）保留。清洗后为空则回退原名。
- **行序**：四张表统一规则——含 `二拍` 的名称把 `二拍` 两字提到名称首位，全部二拍项**独立成组置顶**，组内按 `二拍` 之后城区的首字拼音降序（`盐田 > 坪山 > 南山 > 罗湖 > 龙华/龙岗 > 光明 > 福田 > 大鹏 > 宝安`）；非二拍组在后，按城区首字拼音降序；同首字（如龙岗/龙华）保持表内原相对顺序；找不到城区的行排组内最后。入选规则与展示行序相互独立。
- 城区提取：优先已知区名（罗湖/福田/南山/盐田/宝安/龙岗/龙华/坪山/光明/大鹏/深汕/前海），其次通用 `XX区/镇/街道/新区` 令牌（排除 `工业区/小区` 等伪令牌）。

## 输出结构

1. 标题 `# 深圳法拍资产日报（YYYY-MM-DD）` + 一行概览（各表条数，回退标注）
2. `## 阿里法拍新增关注top10`、`## 京东法拍新增关注top10`：项目名称｜当前价（万）｜评估价（万）｜折价率｜拍卖开始时间
3. `## 阿里法拍成交top10`、`## 京东法拍成交top10`：项目名称｜成交价（万）｜评估价（万）｜折价率
4. 表下注明数据日期；脚注注明折价率口径与入选规则

折价率 = 价格 ÷ 评估价 × 100%，保留 1 位小数。只收录当前价与评估价**均有数据**的项目；
两者任一缺失的项目不入选，因此表内不会出现 `—`，条目数不足 10 条即为当日合格项目不足。

## 故障排查

- 数据源不存在 / sheet 改名 / 列顺序变化：改 `scripts/generate_fapai_daily.py` 顶部 `SHEETS` 配置与 `row_price_cols` 列映射（相对技能目录）。
- 热度列出现新噪声格式：扩充 `parse_heat` 的正则。
- 某表输出为空但用户说有数据：先确认日期标记形态（常见为 Excel 序列值），再看是否被「整行不含 URL」判定误杀。
