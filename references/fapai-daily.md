# 深圳法拍资产日报（原 shenzhen-fapai-daily，已并入 szrehot 每日链阶段 2）

每日从 `D:\Desktop\法拍数据.xlsx` 提取当日法拍数据，生成一份可直接分发的 markdown 日报
（四张表：阿里法拍新增关注top10 / 京东法拍新增关注top10 / 阿里法拍成交top10 / 京东法拍成交top10）。
脚本完成全部解析与格式化，无需手工整理。

## 执行

用托管 Python 环境直接运行脚本（缺省即「今天 + 缺省路径」）：

```bash
PYTHONIOENCODING=utf-8 "C:/Users/Administrator/.workbuddy/binaries/python/envs/default/Scripts/python.exe" \
  -X utf8 "D:/git/opencode/.opencode/skills/szrehot/scripts/generate_fapai_daily.py"
```

可选参数：

- `--date 2026-10-27`（或 `2026年10月27日`）：指定报告日期，缺省为当天
- `--xlsx PATH`：数据源路径，缺省 `D:\Desktop\法拍数据.xlsx`
- `--out-dir DIR`：输出目录，缺省 `D:\Administrator\Documents\大瑀MD`
- `--out PATH`：显式指定输出文件
- `--self-test`：只跑名称清洗回归用例（23 条，含三条验收基准）后退出
- `--audit-names [TSV]`：导出全量「原名 → 精简名」对照并统计精简率/回退率/残留地址词（可选写出 TSV）

输出文件名：`深圳法拍资产日报-YYYY-MM-DD.md`。脚本 stdout 会逐表打印数据日期、块内行数（人工+API）、候选数与入选数；
**回退时退出码 3** 且 md 表头下带 `> ⚠️ 数据日期：…`，此时必须在回复里注明缺失环节。
最终回复中把这些要点带给用户并展示 md 文件。

若报 `ModuleNotFoundError`，先安装依赖再跑：`python -m pip install openpyxl pypinyin`
（同一环境；pypinyin 用于城区拼音排序，缺失时自动退化为字符码降序并告警）。

## 数据源规则

四个 sheet 的结构一致：A 项目名称｜B 网址｜C 当前价/成交价｜D 评估价｜E 拍卖开始时间｜F 热度列。
行按日期分块，日期标记行只在日期列留一个日期，其下方各行（至下一个标记行）属于该日。

**京东两张表读并集**（2026-11-14 起）：人工 `京东`/`京东成交` 当日块 ∪ 步骤 1 的 `京东API`/`京东成交API` 当日块。
理由：人工表会漏抄（2026-11-14 实测漏 6 条含 46 围观标的），API 列表接口也会漏类目归属（同日实测 4 条阳光新境园在 `京东API` 全表 0 命中）——单用任一方都不完整。

| Sheet | 日期列 | 模式 | 并集源 | 入选规则 |
| --- | --- | --- | --- | --- |
| 阿里 | A | 关注 | 无（无公开 API） | **有当前价即入选**；有围观按围观降序，**围观无法解析（缺失/单价噪声）按当前价降序补足 TOP 名额**（2026-11-03 容错），取前 10 |
| 京东 | B | 关注 | `京东API`（日期列 A） | 同上；热度优先取 API 围观数（人工表 F 列常被单价占据） |
| 阿里成交 | A | 成交 | 无 | **有成交价（当前价）即入选**（2026-11-03 放宽）；F 出价人数（热度）数字不为 0 |
| 京东成交 | B | 成交 | `京东成交API`（日期列 A） | **有成交价（当前价）即入选**；人工行 F 含「出价」字样（`X次出价`，`X人围观` 视为流拍剔除）；API 行 `出价次数>0` 且结束时间距业务日 ≤3 天（`API_DEAL_MAX_LAG_DAYS`，防止增量块夹带多日前旧成交） |

API 块列映射（0-based）：`2 物业名称｜5 当前价｜6 评估价｜10 出价次数｜11 围观数｜12 拍卖开始时间｜13 拍卖结束时间｜15 详情链接`。
`评估价 = 0` 归一为缺失（表格显示「—」），不能写成「评估价 0」。

**并集合并规则**：同名（去掉 `二拍/变卖/拍卖` 前缀）+ 价格差 ≤0.05 万（`MERGE_PRICE_TOL`，容忍人工表 149.87/API 149.88 这类取整差）= 同一物业；名称取带处置标记的一方（保住「二拍」置顶），数值与热度取 API 一方。**只并当日块**：任一源当日无块时该源整块不参与（不回退、不跨日混表），stderr 打提示。

两组成交表再按折价率入选：**折价率 > 100% 的项目一律入选**，其余按折价率由低到高补足至 10 条
（超过 100% 的条目多于 10 条时全部保留）。

必须兼容的解析细节（脚本已实现）：

- **日期标记三种形态**：中文文本 `2026年10月27日`、ISO 文本 `2026-10-27`/`2026/10/27`、**Excel 日期序列值**（如 `46322` = 2026-10-27，京东 sheet 已出现）。标记行判定附加条件：整行不含 URL，且非空单元格 ≤2（老块把日期在 A、B 各写一遍）。
- **日期列漂移容错**（2026-11-14）：人工表可能把日期行粘错列——「阿里」sheet 自 2026-11-05 起日期写进 B 列、A 列空，只认上表声明列会把当日块整块漏掉。`find_markers` 按「声明列 + 前 3 列」依次探测，任一列能解析日期即认定为标记行；声明列仅作首选。上表日期列是常态位置，不是硬约束。
- **热度列噪声**：`24544.64元/平`、`商业` 等视为无效行直接忽略；`3.63w人围观` 折算为 36300。
- **价格单位混杂**：`284.49万`、`¥355.62万`、`2亿`、裸数字（按万元计）、`1234元`，统一折算成万元展示。
- **回退规则**（用户已确认）：当天无有效数据块时，回退取该 sheet 最新一天的非空数据块。**回退必须在正文可见**：对应表标题下加一行 `> ⚠️ 数据日期：YYYY-MM-DD（YYYY-MM-DD 当日无有效块，已回退）`，脚本同时向 stderr 打 `[回退]` 并以**退出码 3** 结束（`run_daily_chain` 据此把「法拍资产日报」列入未完成，交付时注明限制）。

## 呈现规则

- **拍卖开始时间**：只保留到日期并统一 `MM-DD`（`11月23日 10:00:00开始` → `11-23`；`2026-10-24 10:00:00结束` → `10-24`）；`进行中/预告中/已结束` 等无日期文本原样保留。
- **项目名称清洗**：日报表内名称只保留 **「区 + 小区（或同级单位）+ 楼栋房号」**，完整规则见下节。
- **行序**：四张表统一规则——含 `二拍` 的名称把 `二拍` 两字提到名称首位，全部二拍项**独立成组置顶**，组内按 `二拍` 之后城区的首字拼音降序（`盐田 > 坪山 > 南山 > 罗湖 > 龙华/龙岗 > 光明 > 福田 > 大鹏 > 宝安`）；非二拍组在后，按城区首字拼音降序；同首字（如龙岗/龙华）保持表内原相对顺序；找不到城区的行排组内最后。入选规则与展示行序相互独立。
- 城区提取：优先已知区名（罗湖/福田/南山/盐田/宝安/龙岗/龙华/坪山/光明/大鹏/深汕/前海），其次通用 `XX区/镇/街道/新区` 令牌（排除 `工业区/小区` 等伪令牌）。

### 项目名称清洗（2026-11-05 起）

删除街道/镇/村/社区/工业区/路/大道/公路/门牌等地址信息、`房产/房屋/不动产/房地产` 后缀、
数字后的 `号`，只保留 **区 + 小区（或同级单位，如大厦/广场）+ 楼栋房号**；
`(破)/(刑)/(第N次)`、`二拍`、`变卖` 原样保留并置于最前（「二拍」丢失会导致置顶分组消失，红线）。
小区名中的 `花园` 删除（`花园城` 属专名保留）；`（第一次）/（第一次拍卖）` 默认一拍直接删除；
`（第二次）/（第二次拍卖）` 删除原标记并在名称最前加 `二拍`（已含 `二拍` 则不重复）。

算法（`generate_fapai_daily.py` 的 `clean_name`）是**从右往左的候选回溯式右截断**，不做多级地名链解析：

1. **剥前缀**：关于/拍卖/变卖、权利人「…名下」、位于/坐落、广东省/深圳市/他市、案号、营销括注；
2. **锚定区名**（罗湖…前海，含 `X新区`）；区名不在开头时按 `深圳市?X区` 兜底；
3. **定位楼栋锚**：首个 `栋/幢/座/号楼/单元/室/铺/层/#`，括号内的「现地址/别名」不参与锚定；
4. **收集候选分隔点**：路/街/巷/道/段、街道/镇/社区/村（`新村` 除外）、工业区/科技园、
   东西南北侧/交汇处、数字+号/区、第N号；
5. **候选回溯**：从右到左尝试，切完必须剩 ≥2 个汉字的像样小区名（纯房号/数量/楼型/分区/路名残片会被拒）；
   命中泛化楼型（研发楼/A单元/塔楼/私宅/北区/一期…）时继续向左，避免把「方大广场」「领翔华府」切掉；
6. **收尾**：删房产类词、数字后的号、面积注记、权证号尾巴、`共计N套`，做括号配平；
   删除小区名中的 `花园`（`花园城` 除外）；结果为空或 <4 字回退原名。
7. **标记归一**（在清洗前预处理）：`（第一次）/第1次` 直接删除；`（第二次）/第2次` 与已有 `二拍`
   全部删除后，在最终名称最前统一加一个 `二拍`。

边界规则：

| 场景 | 规则 |
|---|---|
| `灵芝新村`、`园岭新村`、`益田村` | `村` 属小区/村名自带，不切 |
| `南岭村`、`大芬村`（无小区名） | 属地址，切 |
| `皇御苑A区`、`天麓三区` | 字母/中文数字+区 = 楼栋分区，保留 |
| `90区`、`34-1区`、`宝城48区` | 数字+区 = 地块编号，切 |
| `北区（二期）3806号` | 候选回溯：3806 号是房号 → 回退到小区名 |
| `幸福花园里`、`桃源里家园` | 以「里」结尾的小区名不当路名切 |
| `方大广场…研发楼`、`领翔华府A区…A单元` | 泛化楼型不单独作小区名，向左带上小区名 |
| `…A座1605号商务公寓` | 只删「商务/酒店式公寓」，不删小区名里的「公寓」 |
| `碧海花园`、`星河时代花园` | 小区名中的 `花园` 删除（`碧海`、`星河时代`）；`蛇口花园城` 等 `花园城` 专名保留 |
| `（第一次）`、`（第一次拍卖）` | 默认一拍，整段删除 |
| `（第二次）`、`（第二次拍卖）`、`二拍…` | 删除原标记，名称最前统一加 `二拍`；已有 `二拍` 不重复 |
| 无区名（珠海/中山/东莞等外地房源） | 只保留小区名，**不臆造区名** |
| 切完为空 / <4 字 | 回退原名 |

验收基准（`--self-test` 内嵌，逐字一致）：

| 原始名称 | 期望输出 |
|---|---|
| `南山区内环路以北、前海路以西鼎太风华社区七期14、15座14-308房产` | `南山区鼎太风华七期14、15座14-308` |
| `陈礼雄名下宝安区新安办广深路西侧碧海花园B栋4座307号房产拆迁后可获得的拆迁补偿安置权益` | `宝安区碧海B栋4座307` |
| `宝安区龙华街道梅观高速公路东侧春华四季园14栋三单元10B` | `宝安区春华四季园14栋三单元10B` |

改完清洗规则跑 `--self-test`；`--audit-names [TSV]` 导出全量「原名→新名」并统计。
2026-11-05 全量 11401 条实测：精简 98.5%、回退 0.2%、残留地址词 3.4%
（其中 2.67% 是 `益田村/园岭新村` 这类小区名自带「村」，其余为无深圳区名的外地房源与无小区名的纯地址型资产）。

## 输出结构

1. 标题 `# 深圳法拍资产日报（YYYY-MM-DD）`
2. `## 阿里法拍新增关注top10`、`## 京东法拍新增关注top10`：表前一行 `<p align="center">左右滑动查看表格</p>`，列为 项目名称｜当前价（万）｜评估价（万）｜折价率｜拍卖开始时间
3. `## 阿里法拍成交top10`、`## 京东法拍成交top10`：同样带滑动提示行，列为 项目名称｜成交价（万）｜评估价（万）｜折价率
4. **不输出任何注释/概览/脚注文字**（2026-11-05 用户确认）；唯一例外是**回退告警行**（表标题下 `> ⚠️ 数据日期：…`），否则标题日期与数据日期不符而读者无从察觉（2026-11-14 起强制）

折价率 = 价格 ÷ 评估价 × 100%，保留 1 位小数。**新增关注表**（阿里/京东）有当前价即可入选——有围观人数按围观降序取前 10，**围观无法解析（缺失/被单价等噪声占据）时按当前价降序补足 TOP 名额**（2026-11-03 容错，脚本不开详情页、用当前价作为单价近似的排序键），评估价缺失时折价率显示「—」；**成交表**（2026-11-03 放宽）仅要求有成交价即入选——评估价缺失的成交记录不再整条丢弃，评估价列与折价率如实显示「—」（不编造数据）。

## 故障排查

- 数据源不存在 / sheet 改名 / 列顺序变化：改 `scripts/generate_fapai_daily.py` 顶部 `SHEETS` 配置（4 元组：`sheet, 日期列, 模式, API 并集源 or None`）。
- 并集源（`京东API`/`京东成交API`）改列顺序：改 `make_item_api` 的列号（映射见「数据源规则」）。
- 京东表突然没有 API 补全：看 stderr 的「并集源…当日无块」提示——步骤 1 未跑或 `--skip-jd`，此时只出人工块（仍算当日，不触发回退告警）。
- 成交表混进旧成交：调 `API_DEAL_MAX_LAG_DAYS`（默认 3，人工口径是业务日前一天的成交，周末最多滞后 2 天）。
- 热度列出现新噪声格式：扩充 `parse_heat` 的正则。
- 某表输出为空但用户说有数据：先确认日期标记形态（常见为 Excel 序列值），再看是否被「整行不含 URL」判定误杀。
